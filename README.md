# 🤖 AI Evolution Simulator

AI Evolution Simulator is a web-based AI gaming project where users
create, train and evolve virtual AI creatures.

## 🚀 Features

- User Registration
- User Login
- Logout
- AI Creature Creation
- AI Training
- Creature Evolution
- Generation System
- XP System
- Score System
- Leaderboard
- SQLite Database
- Futuristic UI
- Responsive Design

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite
- Scikit-learn
- NumPy
